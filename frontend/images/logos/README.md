# AI Platform Logos

This directory contains the official logos for various AI platforms.

## Logo Files

Place the following logo files in this directory:

### Major Platforms
- `openai.png` - OpenAI logo
- `anthropic.png` - Anthropic Claude logo  
- `google.png` - Google Gemini logo
- `azure.png` - Azure OpenAI logo

### Chinese Platforms
- `deepseek.png` - DeepSeek logo
- `zhipu.png` - Zhipu AI logo
- `moonshot.png` - Moonshot AI logo
- `volcengine.png` - ByteDance VolcEngine logo

### International Platforms
- `aleph_alpha.png` - Aleph Alpha logo
- `rinna.png` - Rinna logo
- `naver.png` - Naver logo
- `groq.png` - Groq logo
- `cohere.png` - Cohere logo
- `xai.png` - xAI logo
- `mistral.png` - Mistral AI logo

### Custom
- `custom.png` - Custom platform logo

## Logo Specifications

- **Format**: PNG with transparency
- **Size**: 64x64px minimum, 128x128px recommended
- **Background**: Transparent
- **Style**: Official brand logos preferred

## Fallback

If a logo file is not found, the system will automatically fall back to a colored icon based on the platform's brand colors.

## Usage

```dart
PlatformLogo(
  platformKey: 'openai',
  size: 24.0,
)
```
