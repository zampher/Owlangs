# Owlangs
Owlangs 文档翻译工具

### 概览（桌面版）

Owlangs 定位为“所见即所得的翻译工作台”，支持本地安装并连接您自己的大语言模型账号，面向需要高质量文档翻译且忠实保留排版的个人用户和小团队。本次发布仅聚焦桌面标准版/专业版的核心能力，**不**涵盖企业级 Web 版。

### 桌面版核心特性

- **大文档快速翻译**  
  - 专为数十到数百页的论文、技术文档、合同等长文档设计  
  - 从上传到导出，单一工作流即可完成整份文档的翻译  

- **多格式文档支持**  
  - 支持 15+ 种格式：PDF、DOCX、PPTX、XLSX、HTML、EPUB、MOBI、SRT、JSON、TXT 等  
  - 标准版覆盖 PDF/DOCX 等常见格式，专业版解锁所有高级格式  

- **高保真排版保留**  
  - 深度分析 PDF 结构，识别表格、图片、公式、标题、引用等元素  
  - 按照原文排版重新渲染译文，保持结构和格式尽可能接近原文  

- **基于段落的翻译工作台（所见即所得）**  
  - 原文与译文并排查看，支持段落级审查和编辑  
  - 段落状态追踪：已翻译、已修改、已排除、需重试、失败等，问题和进度一目了然  

- **智能分段与内容过滤**  
  - 自动检测不需要翻译的内容（如纯数字、URL、部分代码标识符）并排除  
  - 支持手动设置段落标记如“排除”或“需重试”，确保只有真正必要的内容被翻译和计费  

- **多提供商 LLM 集成与切换**  
  - 可连接 20+ 家主流 AI 平台（如 OpenAI、Claude、Gemini、DeepSeek 等）  
  - 在单个项目内可灵活切换模型：初稿使用更便宜、更快的模型，关键段落使用更高质量的模型进行润色  

- **术语库/术语管理**  
  - 自动从文档中提取术语，构建可重用的术语库  
  - 在翻译过程中应用术语库，确保专业术语在项目间保持一致  

- **多格式导出与友好编辑输出**  
  - 对于 PDF，结果可导出为 Word、HTML、Markdown 等格式，支持进一步编辑、排版或发布  

- **成本控制与本地化友好使用**  
  - 使用您自己的 API 密钥，按使用付费，通常远低于订阅制翻译平台  
  - 数据存储在本地，可与本地解析/推理服务结合，实现内网环境下的安全翻译  

### 目标用户与场景（摘要）

- 需要高质量翻译学术论文和技术白皮书的研究人员和工程师  
- 必须在合同、技术协议和多格式技术文档中保留格式的商业和技术用户  
- 偶尔需要翻译大文档但不想订阅昂贵在线服务的个人用户或小团队
