# Owlangs 版本说明（中文）

## Owlangs 1.4.0.0

### 新功能

1. **支持导出双语文档**：翻译结果可导出为双语文档。
2. **支持批量上传文档**：支持上传文件夹，可穿透文件夹内的压缩包，然后将所有文件放入翻译队列。
3. **任务队列多选与批量下载**：在任务队列中，可以多选任务并按类型批量下载处理后的文档，下载的文档保留上传时的文件夹目录结构。
4. **任务统计与相对路径**：在任务管理中，显示每个任务翻译后的成功/失败片段统计信息，并显示文档的相对路径。
5. **实现 MCP 接口**：实现 MCP 接口，支持文档翻译、文档格式转换等。
6. **实现 CLI 接口**：实现 CLI 接口，允许用户通过命令行在本地执行格式转换和翻译。
7. **支持 PBX 术语表导入导出**：支持导入和导出 PBX 格式的术语表。
8. **MinerU 本地模型版本配置**：可配置本地部署 MinerU 的 5 种模型版本。

### 优化

1. **免安装版改为多文件**：免安装版由单文件改为多文件，减少启动时间。
2. **取消 PDF 导出标题字号处理**：取消 PDF 翻译后导出文件里的标题和子标题字号处理，避免由于 MinerU 识别标题错误导致文本字号混乱。
3. **导出表格默认使用图片**：导出表格默认使用图片。
4. **MinerU 源语言选项描述**：在 MinerU 的源语言选项里，提供所选模型支持语言的详细描述。
5. **首页与工具栏按钮外观**：优化首页按钮和工具栏按钮外观。
6. **翻译超时迁移至 LLM 设置**：将翻译超时的配置迁移到 LLM 的设置里，方便为不同的模型设置不同的超时时间。

### 修复

1. **阅读模式 undo/redo 刷新**：在阅读模式下，undo/redo 虽已更改但前端没有刷新。
2. **标签审核模式 Retry 按钮**：在任务队列里进入标签审核模式后，Retry 按钮无法点击，无法对翻译失败的片段进行 LLM 重翻。
3. **PDF 导出图片选项对表格和公式生效**：PDF 翻译导出时选择图片，但导出的表格和公式仍是文本的问题。

## Owlangs 1.3.1.0

### 新功能

1. **网页提取（Fetch URL）**：支持通过 URL 抓取网页内容，自动提取正文文本与图片，随后可直接进行格式转换或翻译。提取模式支持 **Content（正文提取）** 与 **Full HTML（完整页面）** 两种选择。

### 优化

1. **移除「最近活动」**：主页不再展示最近活动区域；在已有 **任务队列** 的前提下，避免与队列信息重复，简化首页结构。
2. **排除全部片段后的状态恢复**：当用户排除全部片段后重置排除状态，翻译阶段不再错误保留「已全部排除」的旧状态，避免翻译结果中仍出现已排除内容。
3. **MinerU 导入参数统一**：修复导入流程中 `convert_engine` 未正确传递的问题，统一 MinerU 解析参数与错误提示，确保导入与转换阶段使用一致的解析引擎配置。

### 修复

1. **队列式翻译 — 完成态下载列表**：当 TXT、XLSX、PPTX、EPUB、MOBI 等格式在队列中进入 **已完成** 状态时，`downloads` 中缺少 **Markdown（`md`）** 与 **含图 ZIP 版 Markdown（`md_zip`）** 对应下载 URL 的问题。
2. **HTML 排版与电子书导出**：HTML 导出排版不稳定，间或出现版式错乱；依赖该 HTML 的 **EPUB**、**MOBI** 排版也随之不稳定。已改进相关 HTML 生成与 EPUB/MOBI 导出链路，使版式更一致。
3. **翻译进度条显示**：修复 **TXT、SRT、QT_TS、EPUB、HTML** 五种 workflow 在翻译过程中进度条未正常显示的问题。

## Owlangs 1.3.0.0

相对 **1.2.1.0**，本版本在翻译侧引入完整的 **双模式** 与 **任务队列** 能力：既可沿用熟悉的沉浸式工作台，也可改为排队执行并在 **任务队列** 中统一查看进度与下载结果。

### 新功能

1. **两种翻译模式（相对 1.2.1 的核心变化）**  
   - **沉浸式翻译**：在工作区流程内完成上传、提取、词汇表与翻译预览，适合边翻边改、即时对照（与 1.2.1 一致的交互主轴）。  
   - **队列式翻译**：以排队方式提交翻译任务，不必长时间占用当前界面；任务在服务端排队与执行，您在 **任务队列** 中查看状态、进度与完成后下载译文。  
   二者可通过顶栏与任务队列入口切换思路：**沉浸式**对应即时工作台，**队列式**对应后台任务与批量节奏。

2. **任务队列（新）**  
   提供独立的 **任务队列** 列表：展示排队与执行中的翻译任务，支持刷新、取消或移除任务，并在完成后提供多格式下载（具体可用格式以后端配置为准）。列表面向「队列式翻译」产生的结果集中管理。

3. **入口与操作路径**  
   - **顶栏**：在「沉浸式翻译」旁新增 **队列式翻译**，一键进入队列式提交流程；旁侧仍可进入 **任务队列** 查看全部任务。  
   - **任务队列页**：可通过 **队列式翻译** 创建新排队任务，行为与顶栏入口一致。  
   - **队列式翻译全屏页**：提供 **返回任务队列**（工具栏返回与系统返回键）；若译文已改但未写入队列快照，返回前会提示 **保存 / 仍关闭 / 留在当前页**，避免误丢修改。

### 修复与稳定性

1. **DOCX 重建**：改进片段信息与段落定位相关逻辑，提升部分文档在导出 / 重建场景下的还原稳定性。

## Owlangs 1.2.1.0

### 优化

1. **超大 PDF 与 MinerU**：当 PDF 超过 MinerU 单次解析限制时，可先按页或按大小**自动分割**后再送入 MinerU；分割粒度可在 **Settings → Parsing Engine（解析引擎）** 中配置。
2. **翻译前 LLM 连通性检测**：在开始翻译流程前执行一次 **LLM 连接测试**；若测试失败，则**中止翻译**，避免无效排队与错误消耗。
3. **按平台的翻译参数**：**Max Token（最大输出 Token）**与**并发数**改为归属**各 LLM 平台**单独配置，不同平台可使用不同参数（例如本地 **Ollama** 并发设为 **1**，云端 **DeepSeek** 并发可设为 **10**），避免「一刀切」默认值。
4. **公式 LaTeX 自动修复**：当 PDF 提取的公式 LaTeX 质量不佳、公式报错时，支持通过 **LLM 自动修复**链路优化输出；实测 **DeepSeek** 修复效果较好；若使用 **Ollama** 部署的 **translategemma**，修复效果通常不如 **DeepSeek V4 Flash** 等云端模型，可按需切换修复用模型。

## Owlangs 1.2.0.0

### 新功能

1. 支持 macOS 安装部署（macOS 13 及以上，Web 部署）。
2. 除桌面程序外，支持 Web 方式部署。
3. 在既有 OpenAI API 基础上，新增支持 Ollama 与 Anthropic API。
4. 在既有 MinerU 官方云服务接口基础上，新增支持本地部署 MinerU。
5. Web 版用户管理提供三种模式：
   1. **开放模式**：不对用户进行应用准入控制，仅管理员可改配置。
   2. **LDAP 模式**：登录与 AD 通过 LDAP 连接；配置完成后，域内用户无需在 Owlangs 中预先建号即可登录，Owlangs 不存储用户账户信息。
   3. **本地模式**：用户账户由 Owlangs 在服务器本地数据库存储，由管理员自行维护。
6. 提供 MinerU 源语言设置，以支持更多小语种 PDF 解析。
7. 支持通过「转换」按钮完成文档格式转换（例如 PDF 与 DOCX 等互转相关流程）。

### 优化

1. 创建翻译流程时检查是否存在可用 LLM；若无，提示用户先配置 LLM 的 API Key 后再翻译。
2. 本地部署场景下不强制校验 API Key。

### 修复缺陷

1. 重试后的翻译结果未能正确回填到片段。
2. MOBI 翻译后导出的 EPUB 在 macOS「图书」中无法打开。
3. PDF 翻译未排除公式时若快速点击翻译，会出现部分公式片段被错误排除、部分未被排除的不一致现象。

## Owlangs 1.1.0.0

### 新功能

1. 新增翻译目标语言：繁体中文。
2. 支持界面文字语言切换（英文、中文、日文、韩文）。
3. 自动检查新版本；有新版本时在软件主页展示可用版本信息与版本记录。
4. 在文档提取的排除管理面板中新增三个按钮：
   - **「全部排除」**：将所有文本设为不翻译；点击翻译后将跳过所有片段。可与导出配合实现原文格式转换（如 PDF 转 DOCX）。
   - **「恢复自动排除」**：重置用户操作，使排除状态恢复为自动识别结果。
   - **「清除所有排除」**：清除除图片外所有「排除」标记，使全部文本参与翻译；副作用为片段级失败/识别可能出现误差。
5. 支持 ARB（JSON）文档格式（Pro 版）。
6. 支持通过 Ollama 与 OpenAI 兼容接口部署本地大模型（Pro 版）。

### 优化

1. 优化 LaTeX 公式转 Word：可识别混排文本中的 LaTeX 公式，提高转换成功率。
2. AI 平台连接测试提示原为橘红色易产生误解，已优化展示样式。
3. 优化高分辨率下的界面布局。
4. 优化标识符识别：不再将全大写单词一律识别为标识符。

### 修复缺陷

1. 安装路径包含东亚文字时软件无法启动。
2. 翻译完成后进入 Settings 再返回主页，点击下载失败。
3. PDF 翻译导出 DOCX 时，若图片前有文本，可能出现图片被当成文本版式输出。
4. 在初次配置 MinerU 或 LLM Key 之前创建的翻译流程，配置 Key 后仍不可用，需重新创建流程或重启软件。
5. 文本提取阶段未排除语言识别时，翻译后部分汉字（个别含日文）被错误排除，导致片段未翻译。

### 已知问题

1. PDF 中多个公式混在同一段时，部分公式无法识别。
2. PDF 双栏/多栏排版文献中，少数段落前后顺序可能错乱。

## Owlangs 1.0.0.0 — 桌面版首发说明

### 概览（桌面版）

Owlangs 1.0.0.0 是基于 Owlangs 的桌面端首个正式发布版本，定位为「所见即所得的翻译工作台」，支持本地安装并连接自有模型账号，面向需要高质量文档翻译与格式保留的个人用户与小团队。本次 Release 仅覆盖桌面标准版 / 专业版核心能力，不包含企业 Web 版。

### 桌面版核心特性

- **大体量文档快速翻译**
  - 面向数十页至上百页论文、技术文档、合同等场景。
  - 从上传到导出，单次流程可完成整篇翻译。
- **多格式文档支持**
  - 支持 15+ 格式：PDF、DOCX、PPTX、XLSX、HTML、EPUB、MOBI、SRT、JSON、TXT 等。
  - 标准版覆盖常用 PDF / DOCX；专业版解锁全部高级格式。
- **高保真格式保留**
  - 深度解析 PDF 结构，识别表格、图片、公式、标题、参考文献等。
  - 翻译后按原版面重排，尽量保持结构与版式。
- **分段翻译工作台（所见即所得）**
  - 左右分栏展示原文与译文，支持逐段审阅与修订。
  - 片段状态：已翻译、已修改、已排除、需重试、失败等，进度与问题一目了然。
- **智能片段与内容过滤**
  - 自动识别无需翻译内容（如纯数字、URL、部分标识符）并排除。
  - 支持按片段手动标记「排除」或「需重试」，便于计费与质量控制。
- **多平台大模型接入与切换**
  - 可接入 20+ 主流 AI 平台（如 OpenAI、Claude、Gemini、DeepSeek 等）。
  - 同一项目中可切换模型：初稿用高性价比模型，重点片段再用高质量模型。
- **词汇表 / 术语管理**
  - 支持从文档抽取术语并生成可复用词汇表。
  - 翻译时应用术语表，保证专业用语一致，可跨项目复用。
- **多格式导出与后续编辑**
  - PDF 可导出 Word、HTML、Markdown 等，便于继续编辑与发布。
- **成本可控与本地可用**
  - 使用用户自有 API Key，按需付费。
  - 数据可本地存储，并可结合本地解析 / 推理在局域网内安全使用。

### 适用人群与场景（摘要）

- 需要高质量翻译论文、技术白皮书的科研与工程人员。
- 需保持版式的合同、协议与多格式技术文档场景。
- 偶有大文档翻译需求、不希望长期订阅高价在线服务的个人或小团队。

### 版本信息

- **本次 Release 范围**：桌面标准版 / 专业版核心功能首发。
- **企业 Web 版**：多用户协作、域账号集成等将在后续企业版中单独提供。
